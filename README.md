# Sistem Perpustakaan Sederhana

## Deskripsi
Project ini adalah website perpustakaan sederhana yang dibuat untuk mengelola data buku, peminjaman, dan pengembalian buku oleh anggota.

## Fitur
- Menampilkan data buku
- Peminjaman buku oleh anggota
- Pengembalian buku
- Konfirmasi peminjaman dan pengembalian oleh admin

## Teknologi yang Digunakan
- HTML
- CSS
- MySQL

## Cara Menjalankan
1. Buka file index.html di browser
2. Pastikan database sudah dibuat di MySQL
3. Hubungkan database dengan sistem (jika menggunakan backend)

## Tujuan Project
Project ini dibuat sebagai tugas sekolah untuk melatih kemampuan dalam pembuatan website dan pengelolaan database.
